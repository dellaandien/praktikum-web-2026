Berikut adalah beberapa proyek pembelajaran yang saya gunakan untuk mengembangkan keterampilan dalam bidang pemrograman web.

1. Sistem Manajemen Inventori

Teknologi: HTML, CSS, JavaScript, MySQL

Tahun: 2026

Deskripsi Proyek

Sistem Manajemen Inventori merupakan aplikasi untuk membantu pencatatan dan pengelolaan data barang secara terstruktur.

Fitur yang Direncanakan

  • Menambahkan data barang
  • Menampilkan daftar barang
  • Mengubah informasi barang
  • Menghapus data barang
  • Mengelola jumlah stok barang

Tujuan Proyek

Mempelajari pengelolaan data inventori dan penggunaan database MySQL.

2. Aplikasi Kasir

Teknologi: JavaScript

Tahun: 2026

Deskripsi Proyek

Aplikasi Kasir adalah program sederhana yang digunakan untuk menghitung total belanja dan transaksi.

Fitur yang Direncanakan

  • Memasukkan nama barang
  • Memasukkan harga barang
  • Menghitung jumlah pembelian
  • Menghitung total pembayaran
  • Menampilkan hasil transaksi

Tujuan Proyek

Melatih penggunaan JavaScript untuk melakukan perhitungan dan pemrosesan transaksi.
